    TaskCalendar+ について

    TaskCalendar+ は、日々の作業をカレンダーに記録し、タグ別の工数を日報・工数報告へそのまま転記するためのアプリです。

    GitHubでアプリの情報・更新履歴を見る ↗

    💡 詳しい項目は 基本/詳細/タグ管理/Outlook の各タブを参照してください。設定は「保存」で確定、「キャンセル」で破棄できます。

    カレンダー・タスク一覧

    予定を選択してから操作します。文字入力中やダイアログ表示中は、予定のショートカットは使えません。

    キー操作・使える場面
    Ctrl + C予定をコピーカレンダーで選択中の予定
    Ctrl + X予定を切り取りカレンダーで選択中の1件
    Ctrl + V予定を貼り付けカレンダーの選択日に、繰り返しなしで複製
    Ctrl + ドラッグ予定を複製して移動カレンダーの予定をドラッグ
    Delete予定を削除カレンダー・タスク一覧で選択中の予定
    Ctrl + Z操作を元に戻すカレンダーの予定操作。繰り返しの一括作成・一括編集は対象外
    Ctrl + Y / Ctrl + Shift + Z操作をやり直すカレンダーで元に戻した操作

    AI・気づきメモ

    日本語の変換確定中のEnterでは、AIメッセージを送信しません。

    キー操作・使える場面
    Ctrl + Enterメッセージを送信AIモードの入力欄
    Enter改行／メッセージを送信AIモード。「Enterで送信」がOFFなら改行、ONなら送信（初期値OFF）
    Shift + Enter改行AIモード。「Enterで送信」がONでも改行
    Ctrl + Enter気づきメモを保存タスク一覧の「その日の気づき・思ったこと」

    表示倍率

    アプリ全体の文字や表示の大きさを調整します。

    キー操作・使える場面
    Ctrl + ＋ / Ctrl + ＝ / Ctrl + ；拡大どの画面でも使用可。日本語配列ではCtrl + ；も使用可
    Ctrl + −縮小どの画面でも使用可
    Ctrl + 0標準倍率に戻す100%に戻す

    月選択・時刻入力

    ミニカレンダーの月名を押すと、1〜12月の選択画面が開きます。

    キー操作・使える場面
    ← / → / ↑ / ↓月の選択位置を移動月選択画面。上下は4か月分移動
    Home / End1月／12月へ移動月選択画面
    Enter / Space選択中の月を開く月のボタンにフォーカスがあるとき
    Esc日付一覧へ戻る月選択画面
    ↑ / ↓時刻を1分進める／戻す予定の開始・終了などの時刻入力欄

    入力・共通操作

    操作する入力欄やボタンにフォーカス（選択枠）がある状態で使います。

    キー操作・使える場面
    Enter予定を保存予定の編集画面。メモ欄では改行
    Enter設定を保存設定の入力欄。複数行の入力欄では改行
    Enterタグを追加／名前の編集を確定タグ追加欄では追加、タグ一覧では編集を確定
    Ctrl + R画面をリロードトレイの「リロード」と同じ。保存してから操作してください
    Tab / Shift + Tab次／前の操作部品へ移動入力欄・ボタンなど
    Enter / Spaceボタンやスイッチを操作選択中の操作部品
    Escダイアログ・メニューを閉じる設定や予定の編集、タグのメニューなど
