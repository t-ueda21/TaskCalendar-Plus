# TaskCalendar+ v3.0.0-pre.2

Windows x64向けの確認用プレリリースです。インストーラーを手動でダウンロードして利用してください。アプリ内更新では配布しません。

## 変更内容

- **Outlookの予定取得・登録で、アプリ用の識別情報が見つからないと強制終了する不具合を修正しました。** `Find`が正常に返す空オブジェクトを変換前に判定します。取得側と登録側の3か所を修正し、旧版でテストプロセスが強制終了した応答が修正後に正常処理されることを確認しました。
- 月次の合計・残業を小さな横1行に集約。「4時間30分」「1時間0分」のように分まで表示します。日次はタグ別内訳のみを維持します。
- カレンダー・タスク一覧・AI画面の外周を12pxの余白に統一し、画面下端の窮屈さを軽減しました。
- 設定の目次を「基本・連携・アプリ」に整理。目次の背景と本文のグループ見出しの淡い色帯で階層を示し、各項目を囲う枠を減らしました。
- アクセントカラーの色見本を右揃えにしました。
- 設定項目名と操作欄を整列し、AIの設定内に重なっていた枠も整理しました。11ページと保存・取消の動作は維持しています。
- v0.2.1の天気アイコン修正を取り込みました。保存された絵文字やアイコン名ではなく、天気コードから内蔵SVGを描画するため、旧キャッシュでもアイコンを表示できます。天気の説明は選択言語に従います。
- 不明な天気コードを晴れ扱いせず、欠けた気温を0℃として表示しないようにしました。
- v0.2.1から漏れていた日付移動欄の曜日とトレイのアプリ名表示も復元しました。曜日は表示言語に従います。

## 配布・更新

この版はPre-releaseで、Latestには指定しません。通常版用の`latest.json`を添付・変更しないため、この版へのアプリ内更新通知・自動更新はありません。通常版の配布先はv0.2.1のままです。GitHub自体のWatch通知とは別です。

既存アプリで編集中の内容を保存し、トレイメニューから終了してからインストールしてください。同じインストール先への更新は想定された使い方ですが、今回、旧版からの実インストールは検証していません。

## 検証と残る制限

単体・APIテスト、隔離Chromium上での画面操作、旧形式の天気キャッシュ、明暗テーマ・狭い画面・複数言語を確認しています。画面検証の予定・天気・ネイティブ連携は合成データです。

Outlookが空オブジェクトを返す条件でのクラッシュは、実Outlookを起動しないCOM応答テストで再現・修正を確認しました。自動同期が有効なら起動後にもこの取得経路を通ります。ただし、**報告された端末のクラッシュ記録との照合、実Outlookでの再確認は未実施です。すべてのクラッシュが解消したことを保証するものではありません。** ネイティブアプリとインストーラーは今回も実行していません。実Outlook連携（#2・#4・#5）、単一起動の残る実機条件（#12）、実AI応答も未確認です。
