# TaskCalendar+ v3.0.0-pre.3

Windows x64向けの手動ダウンロード用プレリリースです。アプリ内の自動更新では配布しません。

## 変更内容

- Outlookへの送信は初期状態でOFFです。全体設定とタスクごとの同期設定が両方ONの場合に送信します。タスクの同期をOFFにしても両方の予定を残し、以降の送信を停止します。
- Outlookの既存予定表から、登録先・取得元を選択できます。
- Outlookとの作成・変更・削除・キャンセルの同期と、複数日・終日・本文・場所・繰り返しの扱いを拡張しました。参加者情報は表示し、会議通知の送信はOutlookで行います。
- 「今以降」の取得で開始済みの予定を新規取り込みしないよう修正しました。期間指定では期間に重なる複数日予定も対象です（#4）。
- データ保存先ごとの単一起動判定とトレイからの再起動処理を修正しました（#12）。

## ダウンロード

AssetsのEXEを実行するか、ZIPを展開して同じEXEを実行してください。ZIPはインストーラー入りで、インストール不要版ではありません。インストール前に編集中の内容を保存し、既存アプリをトレイから終了してください。

この版はPre-releaseで、Latestに指定せず、latest.jsonも添付しません。通常版の更新先はv0.2.1のままです。

## 検証と制限

公開処理でRustテスト・Clippy・画面関連テストとWindowsインストーラーのビルドを実行します。#12は隔離したデータで多重起動・トレイ再起動・強制終了後の再起動を確認しています。今回、実Outlookの予定を変更するテストと、旧版からの実インストールは行っていません。

時刻は分単位です。一部の会議の繰り返し変更・例外、添付やOutlook固有の属性などには制限があります。Outlook全機能との同等性を保証する版ではありません。対応範囲は[同期仕様](https://github.com/t-ueda21/TaskCalendar-Plus/blob/v3.0.0-pre.3/docs/outlook-sync-matrix.md)を参照してください。
