TaskCalendar+ の最初の公開版です。

- 日・週カレンダーで予定と作業時間を記録できます。
- タグ別の集計、繰り返し予定、Outlook連携、Claude Code / Codex連携に対応しています。
- 文字やUIカラーを整え、新しいアプリアイコンを採用しました。
- 「設定」→「説明」から更新を確認できます。更新前に保存済みデータを自動バックアップします。

Windows 10/11（64ビット）向けです。初回は Assets の x64-setup.exe をダウンロードしてください。
Windowsコード署名は付けていないため、Windowsの警告が表示される場合があります。
