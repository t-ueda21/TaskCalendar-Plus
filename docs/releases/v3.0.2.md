旧版から引き継いだOutlook予定について、開始時刻後のキャンセル・削除がアプリに反映されない問題を修正しました。Windows x64用のEXEと、同じインストーラーを格納したZIPを配布します。

## 修正内容

- 新しく取り込む予定の「現在時刻以降」は維持し、旧予定の取消状態を別途照合します。
- 連携元が記録されていない旧予定には「旧版の予定の連携元を確認」を表示します。その予定表から取り込んだことが分かる予定だけを選んで登録し、もう一度「今すぐ取得」を押してください。登録だけで予定を削除したり、Outlookへ送信したりはしません。
- 別の予定表、同じ識別子を持つ予定のコピー、取得中の編集、送信待ち、取得エラーを考慮し、未確認の状態で削除・再紐付けしないようにしました。
- 日時変更によって連携元確認をすり抜ける経路も修正しました。
- 元の個別回を特定できない旧版の移動済み繰り返し予定や、安定した識別情報がない予定は、警告を表示して保持します。

## 更新と配布

正式版としてLatestに登録し、通常のアプリ内更新でもv3.0.2を案内します。手動の場合はEXEを起動するか、ZIPを展開して中のEXEを実行してください。ZIPはインストーラー入りで、インストール不要版ではありません。

- Rust 227件、画面側40テスト群、JavaScript構文検査、Clippyを確認。実Outlook環境が必要な9件は未実行。

- UIは隔離Chromiumと合成データで確認。実Outlookでの取消操作、今回のインストーラー実行は検証対象外です。
