# TaskCalendar+ v3.0.0（未公開）

予定のOutlook連携、多言語、AIの話し方、集計と日付移動を改善するバージョンです。公開リリースと更新用のタグは作成していません。

## Outlook

新しいタスクには「Outlookにも登録」があります。初期状態はOFFで、「設定→Outlook」から既定ONと登録先予定表を設定できます。連携したタスクの編集・削除も同じ予定表へ反映されます。ローカル保存とOutlookへの反映は別の状態として扱い、失敗した場合は「設定→Outlook」で確認・再試行できます。

現在時刻を基準にする取得は、その時刻以降に開始する予定のみが対象です。開始済みの予定と当日の終日予定は新規取得から外れますが、取り込み済みの過去予定は、その理由だけで削除されません。期間指定では開始日から終了日まで（両端の日付を含む、最大366日）を取得できます。「今週」「今月」「表示中の週」のプリセットも用意しています。

Outlookクラシック版を使用します。会議の招待・参加者への送信は行いません。バックアップ復元ではOutlookへの書き込みリンクを引き継がず、復元を理由に元の予定表を変更しません。

アプリから登録した連携タスクはアプリ側の記録を正とします。別の予定表を取得したり、遅れた取得結果が届いたりしても、この記録を変更・削除しません。Outlook側からこの連携タスクを変更・削除する逆方向の同期は行いません。

## 言語とAI

日本語・English・한국어・简体中文・繁體中文・Español・Français・Deutsch・Portuguêsに対応します。「設定→表示→表示言語」でPCに合わせる、または言語を指定できます。未対応のPC言語は日本語へ戻ります。日本の祝日や地域、勤務時間の設定は言語変更で変わりません。入力したタスク名・メモ・タグ名は翻訳しません。

AIチャットと日次サマリーは選択した言語で回答します。「AIの話し方」で温かさ・絵文字・長さ・口調・カスタム指示を調整し、回答例を確認できます。予定操作の確認手順は個人指示で解除されません。

## 合計・残業と操作

ミニカレンダー下の月次に合計時間と残業時間を表示し、日次はタグ別の時間だけを表示します。タグなし・無効なタグの予定は合計と残業から除き、同日の重なる時間は二重に数えず、工数に含めない休憩を除外します。残業は設定した勤務開始前・勤務終了後の時間です。休日も同じ時間帯を基準に計算します。月次はその月の未来の登録予定も含み、残業は日ごとの合計です。時間を持たない終日予定は0分です。

ミニカレンダーは見出しクリックで日→月→年、選択で年→月→日の順に移動できます。タグ選択には色見本を使い、コピーは共通の線画アイコンに変更しました。

今日への移動は既存の「今日に戻る」ボタンを使います。ミニカレンダーに同じ操作のボタンは追加しません。

設定の転送は、書き出しと読み込みを分けています。読み込みはファイル選択→内容確認→実行の順で、不正なファイルは実行できません。全データ復元では、現在のデータの置き換えを実行前に確認します。

アプリの二回目の起動は新しいアプリを作らず、既存のウィンドウを復帰させます。

## UIの追加見直し

新規タスクでは削除ボタンを表示せず、編集時にのみ表示します。共有フォームのIDを画面ごとに分け、タスク一覧のラベルが同じ画面の入力欄を指すようにしました。キャンセルなどのボタンでEnterを押してもタスク保存には置き換えず、日本語変換の確定中にも保存しません。

狭い画面・拡大表示でヘッダー下の領域を確保し、操作名の縦崩れ、操作ボタンの画面外へのはみ出し、一覧・日次集計・メモの重なりを修正しました。狭い画面ではサイドバーを初期状態で折りたたみ、既存のサイドボタンで開閉できます。

設定タブ、一覧の並べ替え、タグの並べ替え、色パレットをキーボードで操作できます。入力欄と色ボタンに読み上げ名を付け、色の選択やEscによる閉じ方でもフォーカスを保ちます。編集・削除アイコンはコピーと同じ線画形式にしました。

保存済みの天気、配色名、更新状態も表示言語に追随します。タグ・工数とダークモードは即保存、その他の設定は保存ボタンで確定することを画面内に明記しました。繰り返し編集の「今日以降」は「この予定以降」に変更し、実際の対象を明確にしました。

## 追加Issueへの対応

Ctrlクリックで個別選択・解除、Shiftクリックで範囲選択し、タグ・日付・メモを選択した予定だけへ一括変更できます。変更する項目を指定し、全予定の更新時刻を確認して一つのトランザクションで保存します。

選択中のどれかを右クリックしてタグを選んだ場合も、選択中の全件へ同じタグを適用します。タグなしへの変更にも対応し、未選択の予定を右クリックした場合はその1件だけを対象にします。タグが混在している間は、特定のタグを共通の選択状態として表示しません。

複数選択時の追加操作欄と画面上の一括変更ボタンを廃止しました。日付・メモの一括変更と、件数確認付きの一括削除も右クリックメニューから操作します。メニューに選択解除項目は置きません。一括削除は選択した予定だけを一つのトランザクションで削除し、繰り返しの未選択分を残します。

タスク一覧のタグなしは文字付きの中立色バッジにしました。作成・編集モーダルの入力欄と余白を整理し、確認・通知・繰り返し範囲をアプリ内の共通ダイアログへ変更しています。ダブルクリックからの作成に由来する自動文言は表示しません。

ミニカレンダーの折りたたみと年月選択の領域を分け、ホイールによる月・年・年ページの移動を追加しました。設定は表示、勤務時間と休日、タグ管理、AI、Outlook、リンク、起動・常駐、データ、アップデート、ショートカット、説明の11ページです。クイックリンクとURL自動オープンをまとめ、起動・更新・説明を分離しています。
