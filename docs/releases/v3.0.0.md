Windows x64向けの通常版です。アプリ内の更新確認からv3.0.0へ更新できます。

## 今回の変更

- タスク編集はB案を採用。繰り返し予定の変更範囲は、保存直前に「この予定だけ」「この予定と以降の予定」「過去も含むすべて」から選びます。繰り返しルールを変えた場合は後ろの2択です。
- 場所の入力欄と会議通知の案内を削除し、メモは常に表示します。既存の場所情報は保持します。
- タイトル・日付・時刻・メモの文字サイズを統一し、時刻欄の上下矢印の表示を修正しました。
- Outlook送信は初期状態でOFF。全体設定とタスク設定の両方がONのときに送信します。OFFにしても両方の予定を残します。
- Outlookの登録先・取得元の予定表選択、作成・変更・削除・キャンセルの同期、複数日・終日・繰り返しの扱いを改善しました。参加者への会議通知はOutlook側で行います。
- 「今以降」の新規取得範囲（#4）、多重起動判定とトレイからの再起動（#12）を修正しました。
- v3の設定画面、多言語表示、AIの設定、集計、日付移動、天気アイコンの改善を含みます。

## 更新・ダウンロード

設定の「アップデート」から更新を確認してください。v0.2.1とv3.0.0-pre.3より新しいバージョンとして配信します。手動更新の場合はAssetsのEXE、またはインストーラー入りZIPを利用できます。ZIPは展開してEXEを実行してください。

この版はLatestとして公開し、署名付きインストーラーとlatest.jsonを配信します。更新前に編集中の内容を保存してください。

## 検証範囲

B案は38本の画面関連テストと追加8ケースを確認し、コード整理前後の4画面の比較は一致しています。公開処理でもRustテスト、Clippy、画面関連テストを実行してからWindowsインストーラーを作成します。

実Outlookの予定を変更する再試験と、旧版からの実インストールは今回行っていません。時刻は分単位です。一部の会議の繰り返し変更・例外、添付やOutlook固有属性には制限があります。[同期の対応範囲](https://github.com/t-ueda21/TaskCalendar-Plus/blob/v3.0.0/docs/outlook-sync-matrix.md)を参照してください。
