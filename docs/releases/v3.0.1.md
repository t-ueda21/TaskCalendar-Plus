タスク登録・編集画面に、採用したB案のモックを反映した修正版です。アプリ内の更新確認からv3.0.1へ更新できます。

## 画面の修正

- タイトルを先頭に配置し、日付・時刻を横並びにしました。余白、区切り、入力欄と項目名の文字サイズもそろえています。
- 場所と「予定の詳細」の編集欄を外し、メモを常に表示します。既存のOutlook情報は保持し、参加者などの参照情報は該当する予定だけに表示します。
- Outlook送信スイッチを右側に配置し、タスクの選択状態と全体設定に応じて送信・停止状態を表示します。送信は両方ONのときだけです。
- 繰り返し予定の変更範囲は、保存前に選択します。高度な繰り返しの設定は補助操作として残しています。
- 編集画面を開き直した際に先頭へ戻し、狭い画面でタイトルが隠れる問題を修正しました。

## 内部の整理

アプリ全体を点検し、カレンダーとタスク一覧の保存・削除処理を共通化しました。設定の初期値・正規化を保存処理から分離し、Outlookジョブの内部データを名前付きの構造に整理しています。保存形式、公開API、Outlook送信条件は維持しています。

## 更新・配布

設定の「アップデート」から更新を確認してください。Latestとして署名付きEXE・署名・latest.jsonを配信します。手動更新にはAssetsのEXE、またはインストーラー入りZIPを利用できます。

画面・保存処理・Rustテストと独立した変更前後比較を実施し、インストーラー内の画面ファイルもソースと照合します。実Outlookの予定変更と旧版への実インストールは今回の検証対象外です。同期の機能範囲は[同期仕様](https://github.com/t-ueda21/TaskCalendar-Plus/blob/v3.0.1/docs/outlook-sync-matrix.md)を参照してください。
