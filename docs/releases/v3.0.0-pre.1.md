# TaskCalendar+ v3.0.0-pre.1

3.0の動作確認用プレリリースです。Windows x64用インストーラーを手動でダウンロードして利用します。

既にアプリが起動している場合は、編集中の内容を保存して終了してからインストールしてください。今回の作業では、利用中のアプリは自動で入れ替えません。

## アップデート通知

このリリースはPre-releaseとして登録し、Latestには設定しません。通常版向けの `latest.json` を添付・更新しないため、既存アプリの通常の更新確認から、このプレリリースは案内されません。通常版の更新先はv0.2.1のままです。

GitHub自体のWatch・リリース通知は、アプリ内の更新通知とは別です。

## 主な変更

- 設定を11ページへ整理し、アップデート・説明・起動・リンクを分離。
- Ctrl／Shiftによる複数選択、右クリックからタグ変更・一括変更・確認付き一括削除。選択時に画面を押し下げる操作欄は表示しません。
- 日次サイドバーはタグ別内訳、月次は合計・残業時間を表示。タグなしは合計・残業から除外。
- タスクごとのOutlook登録選択、既定OFF／ON設定、編集・削除の反映処理、期間指定の取得。
- 日本語・英語・韓国語など9言語と、AIの話し方・カスタム指示。
- ミニカレンダーの年月選択・ホイール操作、ファイルの読み込み手順、ダイアログ・アイコンを改善。
- 設定の古い内部名と不要なDOM移動処理を整理。
- v0.2.1のOutlook列挙修正を取り込み、正常なS_FALSE応答を取得エラー扱いする退行を修正。

詳しい変更内容は[v3.0.0の説明](https://github.com/t-ueda21/TaskCalendar-Plus/blob/develop/docs/releases/v3.0.0.md)、設定の前後比較は[検証報告](https://github.com/t-ueda21/TaskCalendar-Plus/blob/develop/docs/reviews/v3.0.0-settings-mece.md)に記載しています。

## 確認済み・未確認

ソースの単体・API・隔離Chromiumによる画面操作を検証しています。更新通知の除外は、安定版の更新先と配布するファイルを確認します。

実Outlookでの取得・作成・編集・削除（#2・#4・#5）、更新後の再起動など単一起動の残る実機条件（#12）、実AIの応答品質、今回のインストーラーを実行した結果は未確認です。今回の作業ではネイティブアプリやインストーラーを実行せず、起動中アプリや利用中データも入れ替えていません。
