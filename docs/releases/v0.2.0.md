Ollama／LM Studioを、AIモードと日次サマリーの接続先に追加しました。

- 「設定」→「基本」→「AI」で接続先、接続URL、モデルを設定できます。モデルはプルダウンで選択でき、再取得・手入力・接続テストにも対応します。
- ローカルモデルから予定検索・工数集計・変更提案を利用できます。予定の追加・変更・削除は、確認カードの「確定」を押した後に反映します。
- アプリアイコンを、上段が濃い青・下段2枠が薄い青のカレンダー画像に変更しました。
- ミニカレンダーの「前月／翌月」「前年／翌年」、日・週移動の「前日／翌日」「前週／翌週」を表示し、天気欄と移動ボタンの角丸を統一しました。
- 設定の「説明」の右に「ショートカット」を追加しました。Ctrl＋Rで画面をリロードできます。
- 通知領域のメニューを「最小化」「リロード」「再起動」「閉じる」に統一しました。「最小化」はトレイへの格納、「閉じる」はアプリの終了です。

Ollama／LM Studioのサーバーとモデルは別途用意してください。認証が必要なサーバーには未対応です。模擬サーバーを使った接続・画面・道具の呼び出しを検証済みですが、実際のOllama／LM Studioのモデルを使った推論は未検証です。

未公開のv0.1.8の変更も含みます。予定や設定の保存方法は変わりません。アプリ内の「更新」から更新できます。
