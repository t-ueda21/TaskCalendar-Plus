タスク編集画面の配置と余白を見直し、会議室を開かず確認できるようにしました。Windows x64向けの正式版です。

## 変更内容

- 最新のモックを登録・編集画面に反映。開始日・終了日と時刻の列を揃え、時刻の上下ボタンを維持しました。
- 「終日予定」を日時欄の右上へ移動。メモは常に表示し、会議室・場所は参照情報として表示します。
- タスクにカーソルを合わせると会議室・場所を表示します。通常予定・終日予定の日表示と週表示に対応します。
- 自分用メモとOutlook本文を分離。自分用メモの編集でOutlook本文を上書きしません。
- 追加していた繰り返しの詳細設定とOutlook説明の折りたたみ欄を削除。取得済みの繰り返しルールとOutlook本文のデータは保持します。
- v3.0.2の旧Outlook予定のキャンセル照合修正を含みます。

## 更新方法

アプリの「更新」から取得できます。手動の場合はEXEを実行するか、ZIPを展開して中のEXEを実行してください。ZIPはインストーラー入りです。
