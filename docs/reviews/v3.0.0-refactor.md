# v3.0.0 UI改善・リファクタリング比較報告

2026年10月8日。v3.0.0は未公開です。依頼された機能を先に実装し、動作を固定してから内部を整理しました。必須156ケースは全成功、純粋なリファクタリング前後の18画面は完全一致です。アプリ本体のソースを19,570 bytes（1.24%）・83行削減しました。安定した高速化は確認できていません。

## 担当分担と比較対象

`refactor-with-baseline` Skillを使用し、基準設計・実装・最終検証を別エージェントへ分けました。

| 担当 | エージェント | 作業 |
|---|---|---|
| A：基準設計 | `/root/baseline_a` | 現状調査、ケース・データ・条件の作成、変更前の全試験、基準の固定 |
| B：実装 | `/root/refactor_b` | 固定基準に従う2ファイルの整理 |
| C：最終検証 | `/root/verification_c` | 実装に参加せず、全必須試験・画面・性能を独立に再確認 |
| 調整 | `/root` | 機能修正、担当間調整、文書とローカル確認用ビルド |

[担当記録](v3.0.0-evidence/roles.json)。採用した基準は `baseline-v3` です。機能改善、設定案内の修正と、動作を維持するリファクタリングを別段階で比較しています。

## 再実行

Windows、MSVC、Rust、Nodeを用意し、Playwright 1.62.1とChromiumを導入します。`TCPLUS_TEST_NODE_MODULES` にはPlaywrightを含むnode_modulesの絶対パスを指定します。リポジトリ直下から、新しい出力先で順に実行します。

```text
node scripts/refactor-20261008-checks.mjs . out/recheck/checks all
node scripts/refactor-20261008-ui.mjs . out/recheck/ui-tests
node scripts/refactor-20261008-harness.mjs capture . out/recheck/ui
node scripts/refactor-20261008-benchmark.mjs . out/recheck/benchmark
node scripts/refactor-20261008-snapshot.mjs . out/recheck/source
```

固定基準・変更前ソース・全ログ・比較画像はローカルの `out/refactor-20261008/baseline-v3/` と `out/refactor-20261008/c-final-v3/` に保存しています。新規取得したリポジトリではこの履歴は含まれず、上記は現在ソースの再確認になります。
