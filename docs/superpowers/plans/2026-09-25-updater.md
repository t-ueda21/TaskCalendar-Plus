# Windows Updater Implementation Plan

> Execute inline using superpowers:executing-plans; perform a final independent review.

**Goal:** Package a Windows installer and support signed in-app updates.
**Architecture:** A Rust updater module owns the checked update and database backup.
A small JS controller owns UI state; Tauri commands perform privileged operations.
GitHub Actions builds signed release artifacts from version tags.
**Tech Stack:** Tauri 2, tauri-plugin-updater, SQLite, vanilla JS, GitHub Actions.
**Spec:** ../specs/2026-09-25-updater-design.md

## Global constraints
Windows x64; preserve application identifier and data path; no Authenticode signing;
never commit private keys; do not change repository visibility.

## Review focus
Concurrent clicks; a failed download followed by retry; pending editor contents;
backup failure before installation; first release/feed unavailable.

work remains here to preserve the running app's source/resource locations.
